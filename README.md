# 《足迹》公开工程

《足迹》是一个以中山大学校史资料阅读和学生共创为主题的静态网页工程。本仓库是经过 Stage 07 独立提取与隐私边界审计的公开副本。

公开版包含：

- 经项目审核的历史文字、来源链接和阅读界面；
- 不含成员姓名的九个匿名共创岗位；
- 全站背景音乐《烽火中的足迹》，由访客主动开启；
- 可在本地复现的 Vite 构建、内容校验和隐私扫描。

公开版不包含真人录音、集体照片、开发纪事、成员身份字典、内部候选稿或原宣传片。历史影像副本也不随本次公开构建发布；历史文字仍保留来源链接和不确定性说明。

## 在线体验

https://sysu-footprints-open.pages.dev/

## 核心功能

- 历史时间轴与互动地图；
- 1938—1945 双视角阅读；
- 1947 卷宗与九步空间叙事；
- 2024 百年回望与匿名创作者终章；
- 背景音乐《烽火中的足迹》，支持播放、暂停、循环和音量调节。

## 技术栈

React、TypeScript、Vite，以及 Node.js 测试脚本和 Playwright 浏览器验收。

## 本地运行

npm ci
npm test
npm run validate:content
npm run typecheck
npm run build
npm run privacy:audit

需要 Node.js 22.12 或更高版本。构建产物写入 dist/，不会修改原始工程。
